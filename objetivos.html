Objetivos

Objetivo general

Diseñar y desarrollar un sitio web informativo para presentar los componentes principales del Proyecto Integrador I, utilizando HTML5, CSS3, JavaScript y el framework Materialize.

Objetivos específicos

  • 1. Organizar la información
    Estructurar el contenido del proyecto en secciones claras y enlazadas desde un menú de navegación.
  • 2. Aplicar diseño responsivo
    Usar Materialize para construir una interfaz adaptable a computadores, tabletas y teléfonos.
  • 3. Personalizar la interfaz
    Incluir estilos propios para mantener una identidad visual coherente en todas las páginas.
  • 4. Integrar JavaScript
    Añadir interacciones básicas, como mensajes de bienvenida y validación del formulario de contacto.
  • 5. Mostrar el trabajo del equipo
    Presentar los integrantes, los avances y los objetivos definidos durante el desarrollo del proyecto.
